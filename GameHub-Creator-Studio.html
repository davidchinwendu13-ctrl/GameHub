WELCOME TO YOUR GAMING WORLD

Discover Roblox with GameHub.

GameHub is a gaming discovery hub designed to make finding your next Roblox experience easier. Browse games, search by name or genre, and jump into experiences on Roblox.

🎮 Discover gamesExplore a growing catalogue of Roblox experiences across different genres.
🔎 Search the catalogueFind games by title or keywords using the GameHub search.
🚀 Play on RobloxChoose a game and open its Roblox experience in a new tab.
👤 Find playersLook up public Roblox user profiles by username.
How GameHub works: GameHub helps you discover Roblox experiences; the actual Roblox games run on Roblox, not inside this website.

What is coming next?
More game listings, live game thumbnails, secure account linking, community features and a hosted version of GameHub. Some future features need a secure server and Roblox's approved sign-in process.

ABOUT THE PROJECT

Welcome to GameHub

One home for gaming

GameHub is being built as a place to discover Roblox experiences and find other players.

What works in this version:
• Roblox game catalogue and search
• Links to Roblox experiences
• Public Roblox username search

This is a local prototype. Accounts, chat, cloud saves, multiplayer, moderation tools and secure Roblox OAuth need a hosted backend before public launch.
